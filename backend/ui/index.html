访问模式

局域网模式 — 无需登录
局域网免登录：所有 API 和 Web UI 直接可用，没有 token 过期问题。
需要恢复鉴权时，在 .env 里设 MSC_AUTH_ENABLED=true 并重启容器。

照片源（msc-pic）

添加本机目录或局域网共享（SMB/WebDAV）。worker 渐进扫描：先占位，再逐张生成缩略图， 随时可暂停/继续，中断后从断点接着走，不会重复。
本地目录必须在 MSC_PIC_ROOTS 白名单内（默认 /home/astro/photos），并已挂载进容器。

嵌入模型（语义搜索）

任意 OpenAI 兼容 embeddings（llama.cpp / LM Studio / Ollama / OpenAI）。测试按钮会嵌入一句话并回报维度。
llama.cpp 提供嵌入时需 -ub 4096，否则长记忆会失败。未配置时搜索自动退回关键词。

重排模型（可选）

llama.cpp /v1/rerank（--rerank）或 Cohere 方言；未配置时混合搜索只用余弦排序。

语音转写（whisper）

llama-server 的 whisper 端点（--model ggml-*.bin）或其他 /v1/audio/transcriptions 服务。语音页用它。

回响评注模型（可选）

评注专用的独立模型 API；留空自动回退 chat 卡。评注可存成 md 记忆文件（默认存进记忆目录，下个同步周期自动入库成为普通记忆）。
